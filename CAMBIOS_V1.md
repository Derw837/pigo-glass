# Entrega V1

Esta base prioriza el flujo comercial completo antes de afinar fórmulas de fabricación:

- Captación pública.
- Asesor especializado con foto.
- Alcance cerrado para evitar uso general de OpenAI.
- Clasificación automática, estimación condicionada o visita técnica.
- Leads y seguimiento.
- Materiales y precios administrables.
- Importación Excel.
- Galería por categorías.
