# Catálogos usados como base

El catálogo inicial se extrajo de los PDF compartidos durante el diseño del proyecto:

- CEDAL · Catálogo de Sistemas · Versión 2026.
- Andesía Ecuador · Catálogo.

La extracción automática conserva referencia, marca, nombre/contexto, categoría aproximada y página de origen cuando fue posible. Antes de utilizar una referencia para fabricación, valida nombre, sistema, espesor, medida y compatibilidad contra el catálogo original. Los precios quedan en cero.
